TuxBooks 0.1.8 makes bulk operations survive a connected sync folder. With
sync enabled, forgetting a large Reading history used to abort partway
through: the sync engine drains its queue in the same database window, and
one write waiting too long for the database lock cancelled the whole run,
leaving an arbitrary slice of books forgotten.

## Fixed

- Bulk Forget now rides out database write contention: when another writer (the sync engine, typically) holds the database, each book retries instead of the entire run failing at the first wait. A run can no longer stop halfway because sync happened to be busy.
- A book whose post-commit bookkeeping loses a contention race is still counted as forgotten instead of silently vanishing from the result.

## Install on Ubuntu/Debian

```sh
sudo apt install ./tuxbooks_0.1.8_amd64.deb
```

Or run the portable AppImage:

```sh
chmod +x tuxbooks-0.1.8.AppImage
./tuxbooks-0.1.8.AppImage
```

`SHA256SUMS.txt` verifies the downloads. The SBOM is published next to
the installers.
