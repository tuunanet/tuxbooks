TuxBooks 0.1.3 syncs your reading between machines through a cloud
folder. Point each copy at a folder your own cloud service keeps in
sync and reading progress, bookmarks, highlights, and collections
follow you, with no provider accounts. Sync repairs its own failures
and shows trouble outside Settings. Conflict review catches edits an
automatic merge would overwrite, and books waiting for their files have
their own list, so you can forget one on a single machine without
touching the others. Library records are durable now. A book keeps its
identity, collections, and reading history when its file moves or
leaves the library, duplicate copies collapse into one entry, and
editions can be linked to share progress. Imports can be cancelled
mid-run, watched folders show their scan status, and scans are faster.

## New

- Reading progress, bookmarks, highlights, and collections follow you between machines through a folder your own cloud service keeps in sync. No accounts, no provider APIs.
- Sync repairs its own failures. Conflict review covers edits an automatic merge would overwrite, and sync trouble is visible outside Settings.
- Books waiting for their files have their own list and can be forgotten on a single machine.
- Durable library records: a book keeps its identity, collections, metadata, and reading history when its file moves or leaves the library. A moved file relinks to its record, and older libraries upgrade safely on first launch.
- Reset and Forget are separate actions. Reset keeps the book's identity. Forget starts the file over as a fresh unread entry and puts the old record in a 30-day trash you can restore from.
- Duplicate copies of a book collapse into one library entry.
- Books can be linked as editions that share percentage-only progress.
- Imports and unwatching can be cancelled and report their progress. A quit mid-import no longer strands the books it already saved, and large imports walk each folder once.
- Watched folders appear in Settings the moment you add them, each row tagged with its scan status.
- The library can be filtered by format.

## Changed

- The reader shell and the library view are split into smaller focused units.
- Settings splits the sync and detail views apart, and viewer settings now live on one page.

## Fixed

- A fresh sync folder is adopted cleanly, and starting over moves no files.
- The device name field no longer resets while you type, and stat card values line up.
- Settings > Sync stays responsive when the issue, waiting, or trash lists run long.
- The library scrollbar thumb stays under the held cursor.
- The reader positioning tooltip stays cleared after the pointer leaves.
- Dependency updates clear the open npm security advisories.

## Install on Ubuntu/Debian

```sh
sudo apt install ./tuxbooks_0.1.3_amd64.deb
```

Or run the portable AppImage:

```sh
chmod +x tuxbooks-0.1.3.AppImage
./tuxbooks-0.1.3.AppImage
```

`SHA256SUMS.txt` verifies the downloads. The SBOM is published next to
the installers.
