This pre-release restores a forgotten book without its file in one step, adds per-row Erase to the Forgotten books list, and moves reading history into Settings. It is a tester preview of 0.1.12; the stable release follows once this build has been used.

## New

- **Restore a forgotten book without a file in one step.** Restore on a forgotten book whose file is gone now asks for the file and lands the record back in the library with its reading data. Bytes that match the snapshot prove it is the same book; different bytes offer only the lossless choices (link as a different edition, or restore without a file). A picked file that another library entry already owns takes that entry's role instead of overwriting it.
- **Per-row Erase for forgotten books.** Each Forgotten books row has an Erase button next to Restore, so one record can be removed permanently instead of waiting out the 30-day window. A confirm dialog fronts it, and the erase closes the entry on every synced machine. The row's Restore-without-file shortcut is gone; restoring a fileless record asks for a file.
- **Reading history lives in Settings → History.** The former sidebar view is now a History section in Settings, split into Detached records and Forgotten books tabs, so the library sidebar stays a set of browsing views.
- **Detached rows label empty duplicates.** A detached record that duplicates another entry shows what it is a duplicate of, so an empty stale row no longer looks like a lost book.

## Changed

- 13 dependency updates (patch and minor releases, no behavior changes).
- Two RustSec advisories patched in the sidecar's dependencies: tokio `AsyncFd` constructor unsoundness (the affected constructors are never called here) and a `Url::origin()` stack overflow on deeply nested `blob:` URLs (the sidecar only parses database URLs it builds itself). Both are lockfile-only upgrades.

## Install on Ubuntu/Debian

```sh
sudo apt install ./tuxbooks_0.1.12-pre.2_amd64.deb
```

## Install on Arch/Manjaro

```sh
sudo pacman -U ./tuxbooks-0.1.12-pre.2-1-x86_64.pkg.tar.zst
```

## Portable AppImage

No `libfuse2` install is needed; the embedded runtime is statically linked.

```sh
chmod +x tuxbooks-0.1.12-pre.2.AppImage
./tuxbooks-0.1.12-pre.2.AppImage
```

On a system with no FUSE at all, run it with
`APPIMAGE_EXTRACT_AND_RUN=1`.

`SHA256SUMS.txt` verifies the downloads. The SBOM is published next to
the installers.
