0.1.12 is the stable release that follows the tester previews. It carries two library layout fixes: the search placeholder fits the sidebar, and a long metadata chip no longer stretches the book detail view past its card.

## Fixed

- **The library search placeholder fits.** The sidebar was 224px wide, which left the "Search library or collections" placeholder clipped after padding. It now defaults to 288px with a matching minimum, so the full placeholder is visible.
- **A long author or subject chip no longer widens the detail view.** A chip with enough text stretched the metadata fields past the card's right border. Chips now wrap inside their row, so every control stays inside the card.

## Install on Ubuntu/Debian

```sh
sudo apt install ./tuxbooks_0.1.12_amd64.deb
```

## Install on Arch/Manjaro

```sh
sudo pacman -U ./tuxbooks-0.1.12-1-x86_64.pkg.tar.zst
```

## Portable AppImage

No `libfuse2` install is needed; the embedded runtime is statically linked.

```sh
chmod +x tuxbooks-0.1.12.AppImage
./tuxbooks-0.1.12.AppImage
```

On a system with no FUSE at all, run it with
`APPIMAGE_EXTRACT_AND_RUN=1`.

`SHA256SUMS.txt` verifies the downloads. The SBOM is published next to
the installers.
