TuxBooks 0.1.2 brings book mode to the readers: press B in an EPUB or PDF
and the reading area becomes a two-page spread that turns like a book.
Spreads navigate instantly, are measured up front so the geometry is
known before they render, and the PDF spread shares the existing
document, cache, and render worker. The toggle lives in the appearance
popover, and the setting is remembered between sessions. Under the hood,
renders are serialized so pages stop fighting over the worker, and far
thumb drags are captured reliably.

## New

- Book mode in both readers: B toggles a two-page spread view in EPUB and PDF, with clicks in the page zones and arrow keys turning the spread. The toggle also lives in the appearance popover, and the choice is remembered per session.
- Spread geometry is laid out up front, so a turned spread renders in place instead of measuring mid-turn.
- The PDF book view renders the spread through the same document, cache, and render worker as the normal view, so nothing is duplicated.

## Fixed

- PDF worker renders are serialized, and drag capture works again when the scrollbar thumb travels far in one drag.

## Install on Ubuntu/Debian

```sh
sudo apt install ./tuxbooks_0.1.2_amd64.deb
```

Or run the portable AppImage:

```sh
chmod +x tuxbooks-0.1.2.AppImage
./tuxbooks-0.1.2.AppImage
```

`SHA256SUMS.txt` verifies the downloads. The SBOM is published next to
the installers.
