TuxBooks 0.1.4 turns Settings into a draggable window that follows the
theme of what is under it. Open it over the library or the reader, move
it anywhere, and close it with X or Escape. Over the reader it uses the
reader's live theme, so a pinned light book stays light inside a dark
app. Default EPUB pages now follow the app theme, so a dark app shows
dark pages, and the reader appearance controls are rebuilt as an
icon-led panel. Reader engine updates from Readium make EPUB navigation
steadier.

## New

- Settings opens as a draggable window over the library or the reader instead of replacing the view. Close it with the X or Escape, and open it from the reader toolbar gear.
- The settings window over the reader paints in the reader's live theme. A pinned light book stays light in a dark app, an unpinned reader follows app theme flips, and Viewer settings repaint the book and the window together.

## Changed

- Default follows the app theme. A dark app now renders Default EPUB pages dark instead of publisher-white inside dark chrome. Explicit Light, Paper, or Dark picks still pin, and PDF Default still means Smart dark in a dark app.
- The reader appearance popover is an icon-led panel: an Appearance header, symbols on every control, font-family previews, icon choices for alignment, layout, and columns, and labeled theme swatches with Light and Dark together in both theme menus.
- Reader and Settings share one settings store, so an edit from either side cannot overwrite the other with a stale copy.

## Fixed

- Rapid EPUB navigation or preference changes no longer leave a stale or blank page behind, and a page hidden for more than ten seconds during a frame load no longer blocks all further navigation.
- Closing the reader no longer hangs on fixed-layout publications.
- The one open npm advisory (minimatch, moderate) affects build tooling only and ships in nothing users run. Its patched version is younger than the 30-day release-age floor, so it waits for the regular dependency updates around 2026-11-26.

## Install on Ubuntu/Debian

```sh
sudo apt install ./tuxbooks_0.1.4_amd64.deb
```

Or run the portable AppImage:

```sh
chmod +x tuxbooks-0.1.4.AppImage
./tuxbooks-0.1.4.AppImage
```

`SHA256SUMS.txt` verifies the downloads. The SBOM is published next to
the installers.
