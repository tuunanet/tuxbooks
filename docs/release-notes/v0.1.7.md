TuxBooks 0.1.7 fixes bulk Forget on large Reading histories: on a library
of about 10,000 history books, each Forget attempt moved only an arbitrary
slice (125 books, then 53) and showed an error, because the app gave up on
the operation after 60 seconds while the work was still running.

## Fixed

- Long library operations are no longer abandoned mid-flight. The main process now judges the sidecar by silence: any progress the sidecar streams keeps the operation alive, and only a sidecar that stops responding for 60 seconds fails the call. Bulk Forget of a large history and big imports both complete instead of stalling at the minute mark.
- Reading history reloads at most once per event window while a bulk Forget streams one event per book. The old per-event reloads queued thousands of list queries behind the writes and made the operation slower the bigger the history.

## Install on Ubuntu/Debian

```sh
sudo apt install ./tuxbooks_0.1.7_amd64.deb
```

Or run the portable AppImage:

```sh
chmod +x tuxbooks-0.1.7.AppImage
./tuxbooks-0.1.7.AppImage
```

`SHA256SUMS.txt` verifies the downloads. The SBOM is published next to
the installers.
