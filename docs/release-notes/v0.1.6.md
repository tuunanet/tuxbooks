TuxBooks 0.1.6 makes Reading history usable at real library sizes: Forget
selected now works above 1,000 books, and a 10,000-book history lists and
selects without freezing. Collections become sidebar places instead of a
filter beside the library.

## New

- Collections are sidebar places now. The sidebar picks one active place at a time: a smart section, Reading History, or a union of one or more collections. Pinned collections can be reordered and collapsed, and the pin stays on the device.

## Fixed

- Forget selected no longer fails with "invalid bookIds" on histories bigger than 1,000 books. The selection now rides several bounded invokes, and a failed batch reloads the list so the books already forgotten show.
- Reading history renders a bounded window instead of one card per book, and selection checks run on a set instead of array scans. A 10,000-book history stays responsive while listing, scrolling, and select-all.

## Install on Ubuntu/Debian

```sh
sudo apt install ./tuxbooks_0.1.6_amd64.deb
```

Or run the portable AppImage:

```sh
chmod +x tuxbooks-0.1.6.AppImage
./tuxbooks-0.1.6.AppImage
```

`SHA256SUMS.txt` verifies the downloads. The SBOM is published next to
the installers.
