TuxBooks 0.1.5 fixes a sync merge that left duplicate book cards and an
inflated count on a device joining an existing sync library.

## Fixed

- Joining an existing sync library on a second device now reloads the library after the identity merge. A re-keyed book leaves one card, and the header count matches what is stored.

## Install on Ubuntu/Debian

```sh
sudo apt install ./tuxbooks_0.1.5_amd64.deb
```

Or run the portable AppImage:

```sh
chmod +x tuxbooks-0.1.5.AppImage
./tuxbooks-0.1.5.AppImage
```

`SHA256SUMS.txt` verifies the downloads. The SBOM is published next to
the installers.

**Full changelog:** https://github.com/tuunanet/tuxbooks/compare/v0.1.4...v0.1.5
