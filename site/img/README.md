# Screenshots

Drop your PNGs here with these exact filenames and they will appear on the
site automatically (no code changes needed):

- `library.png` — the library / bookshelf view
- `pdf-reader.png` — the PDF reader in action

Recommendations:

- Landscape, roughly 1600×1000 or 1920×1080 (16:10 / 16:9)
- PNG format, cropped to the app window
- Keep file sizes reasonable (< 1 MB each if possible) — e.g. compress with
  `pngquant` or export at 2x and downscale

While a file is missing, the site shows a styled placeholder with the expected
filename. To add or rename slots, edit the figures in `site/index.html`
(update both `src` and `alt`).
